# Räumecheck

Eine kleine statische Web-App zur Ausstattungskontrolle von Räumen.

## Inhalt

- Auswahl eines Raums
- Checklisten-/Wizard-Workflow
- Bewertung der Ausstattung
- Ergebnisanzeige im Browser

## Starten

Einfach die Datei `Räumecheck.html` im Browser öffnen.

## Hinweis

Dieses Projekt wurde als leichtgewichtiges Frontend ohne Build-Tool erstellt.
